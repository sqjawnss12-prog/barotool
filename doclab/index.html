PDF 정리 도구

여러 PDF를 합치거나 한 PDF에서 필요한 페이지만 추출·삭제·회전합니다.

PDF 여러 개를 선택하세요

선택한 순서대로 하나의 PDF로 합칩니다.

페이지 번호는 1부터 시작합니다.

PDF 파일을 서버에 올리지 않고 정리

문서랩은 선택한 PDF를 브라우저 메모리에서 읽고 결과 파일을 생성합니다. 계약서·과제·보고서처럼 외부 업로드가 신경 쓰이는 문서를 가볍게 정리할 때 사용할 수 있습니다.

PDF 합치기

여러 PDF를 파일 선택 순서대로 하나로 묶습니다. 보고서 본문과 부록, 스캔 문서 여러 개처럼 따로 받은 파일을 한 문서로 정리할 때 유용합니다.

페이지 추출·삭제

1-3,5처럼 범위를 입력하면 필요한 페이지만 새 PDF로 만들거나 반대로 해당 페이지만 제거할 수 있습니다. 원본 파일은 변경되지 않습니다.

페이지 회전

스캔 방향이 잘못된 PDF를 90°·180°·270° 회전해 새 파일로 저장합니다. 특정 페이지만 지정하거나 입력칸을 비워 전체 페이지를 회전할 수 있습니다.

다른 무료 도구

PDF에 넣을 이미지는 사진 용량 줄이기로 정리하고, 안내문에 넣을 링크는 QR공방에서 QR코드로 만들 수 있습니다. 다른 계산·이미지 작업은 바로툴에서 이어서 사용할 수 있습니다.

암호가 걸린 PDF도 되나요?

암호화된 PDF는 브라우저 라이브러리에서 열지 못할 수 있습니다. 이 경우 원본 프로그램에서 암호 보호를 해제한 복사본으로 작업하세요.

파일 용량 제한이 있나요?

서버 제한은 없지만 브라우저 메모리를 사용하므로 매우 큰 PDF나 페이지가 많은 문서는 기기 성능에 따라 처리되지 않을 수 있습니다.
