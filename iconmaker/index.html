파비콘이 필요한 이유

파비콘은 브라우저 탭, 즐겨찾기, 모바일 홈 화면, 검색 결과 등에서 사이트를 구분하는 작은 브랜드 아이콘입니다. 한 장의 원본으로 여러 크기를 준비해 두면 기기별 표시 품질을 맞추기 쉽습니다.

어떤 파일이 만들어지나요?

기본 브라우저용 favicon.ico와 32×32 PNG, iOS 홈 화면용 180×180, 웹앱용 192×192·512×512 PNG, 그리고 웹앱 아이콘 경로가 들어간 site.webmanifest를 제공합니다.

이미지 준비도 같이 하기

원본 로고의 픽셀 크기를 먼저 맞추려면 바로툴 이미지 크기 변경, 파일 형식을 바꾸려면 이미지 형식 변환을 이용할 수 있습니다. 홍보물 링크를 QR로 만들 때는 QR공방으로 이어서 작업할 수 있습니다.

이미지가 서버에 업로드되나요?

아니요. 선택한 이미지는 브라우저의 Canvas에서 처리하며 별도 업로드 API를 사용하지 않습니다.

ICO 파일도 실제로 만들어지나요?

네. 32×32 PNG 데이터를 ICO 컨테이너에 넣어 현대 브라우저와 운영체제에서 사용할 수 있는 favicon.ico 파일로 다운로드합니다.
