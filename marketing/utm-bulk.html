UTM 대량 생성기

여러 랜딩페이지에 같은 캠페인 규칙을 한 번에 적용합니다. 입력 내용은 서버로 전송되지 않습니다.

URL과 필수 UTM 값을 입력하세요.

언제 대량 생성이 유용한가?

광고 소재별로 랜딩페이지가 여러 개이거나, 뉴스레터·제휴·SNS 캠페인에서 여러 링크에 같은 source·medium·campaign 규칙을 적용할 때 반복 입력을 줄일 수 있습니다.

UTM 이름을 일관되게 쓰는 이유

같은 채널을 naver와 Naver처럼 섞어 쓰면 분석 화면에서 서로 다른 값으로 분리될 수 있습니다. 팀에서 source와 medium의 표기 규칙을 먼저 정하고 반복 사용하는 것이 좋습니다.

주의할 점

내부 사이트 이동 링크에는 UTM을 무분별하게 붙이지 않는 편이 좋습니다. 이 도구는 추적 링크를 생성할 뿐 클릭·전환 데이터 자체를 수집하거나 분석하지 않습니다.

한 개 링크만 만들려면 UTM URL 생성기, 광고 수익성을 계산하려면 광고 손익 계산기를 이용하세요.
