프린트핏

사진·포스터·전단 디자인 전에 원본 이미지가 원하는 크기로 인쇄 가능한지 계산합니다.

픽셀 → 인쇄 크기

인쇄 크기 → 필요한 픽셀

자주 쓰는 출력 크기

인쇄 크기(inch) = 픽셀 ÷ DPI, 필요한 픽셀 = 출력 크기(inch) × DPI입니다. DPI 메타데이터 숫자만 바꾼다고 원본 픽셀 디테일이 늘어나는 것은 아닙니다.

어떤 때 쓰나요?

인쇄소에 사진·포스터·전단 파일을 보내기 전 원본 해상도가 충분한지 확인하거나, 디자인을 시작할 때 목표 출력 크기에 필요한 캔버스 픽셀을 정할 때 유용합니다. 실제 제작 기준은 업체·인쇄 방식마다 다를 수 있으므로 최종 주문 전 해당 인쇄소 가이드를 우선 확인하세요.

화면 자체의 픽셀 밀도를 계산하려면 바로툴 PPI 계산기, 이미지 픽셀 크기를 바꾸려면 이미지 크기 변경을 이용하세요.

다른 무료 도구는 바로툴에서, 광고 효율 계산은 마케팅셈에서 사용할 수 있습니다.
