상품 실제 단가 비교

가격·할인·배송비·증정수량을 입력하세요. 같은 단위끼리 비교하면 최저 단가를 자동 표시합니다.

계산 기준

실결제액 = 표시가격 × (1 - 할인율) + 배송비, 실제 확보량 = 기본 수량/용량 + 무료 증정 수량/용량입니다. 실제 단가는 실결제액 ÷ 실제 확보량으로 계산합니다.

예를 들어 500g 상품이 10,000원이고 20% 할인, 배송비 3,000원이라면 실제 지출은 11,000원입니다. 같은 상품 1+1로 총 1,000g을 받는다면 100g당 단가는 1,100원이 됩니다.

여러 쿠폰이 순차 적용되는 경우에는 쿠폰셈 중복 할인 계산기에서 최종 할인율 또는 결제액을 먼저 확인하면 더 정확합니다.

자주 묻는 질문

1+1은 어떻게 입력하나요?

기본 수량에 구매하는 양을, 무료 증정 칸에 추가로 받는 양을 입력하면 됩니다. 500g 1+1이면 기본 500g, 증정 500g으로 넣습니다.

배송비도 단가에 넣어야 하나요?

실제로 그 상품을 사기 위해 배송비를 반드시 내야 한다면 포함하는 편이 정확합니다. 무료배송 주문에 함께 담는 상품이라면 0원으로 두면 됩니다.

g와 kg를 직접 비교할 수 있나요?

현재는 같은 표시 단위끼리 비교하도록 단순화했습니다. kg 상품은 총 용량을 g로 환산해 입력하면 됩니다. 1kg = 1,000g입니다.
